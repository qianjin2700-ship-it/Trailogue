# 09 — 验收标准与测试场景

## 1. 模块验收标准

### F01 登录
- [ ] 首次打开 3s 内静默完成登录，无需任何操作
- [ ] 拒绝昵称授权不影响任何功能
- [ ] 未同意隐私政策时无法进入上传流程

### F02 相册管理
- [ ] 创建/重命名/删除相册即时生效，列表刷新正确
- [ ] 删除需二次确认且列出将删除的内容类型

### F03 上传
- [ ] 5~50 张数量边界：4 张可存草稿但「生成」置灰；50 张后无法继续添加且提示删除/更换；上传页实时显示「已选择 X/50 张」
- [ ] 任何情况下系统不自动截断、丢弃或覆盖照片（仅用户主动删除）
- [ ] **上传前检查**：格式不支持（如 BMP/RAW）被拒绝并提示；超大文件（>20MB）被拒绝；损坏文件被拒绝；重复照片弹窗提示选择保留或删除
- [ ] 单张失败可重试，重试不重复占位；支持批量重试
- [ ] 上传过程显示：总体进度、单张状态、成功数、失败数、失败原因
- [ ] WiFi 下 10 张原图+缩略图 < 90s
- [ ] 中断网后恢复，失败项可续传
- [ ] 删除照片后可继续补充上传

### F04~F06 元数据
- [ ] 完整 EXIF 照片：时间/地点/方向正确读取并绿标展示
- [ ] 无 EXIF 照片：按二级规则推断且黄标带置信度
- [ ] GPS 境外/无效值被识别并降级
- [ ] 聚类：6h/30km 阈值切组正确；内容明显切换（场景/地标变化）且时间地点无法判定时按内容切组；组数 ≤10
- [ ] 同坐标照片只产生一次逆解析调用（geo_cache 命中）
- [ ] 分批处理：每批 ≤5 张；批间结果持久化；人为中断后从首个未完成批次续跑，已完成批次不重算（可通过 ai_jobs.batches 与调用次数验证）

### F07 视觉理解
- [ ] 地标照片产出 landmark fact；人脸不出现身份描述
- [ ] 视觉单批失败自动重试 1 次；仍失败计入 failed_photo_ids 并阻断生成（40903），前端提供「重试失败项 / 移除失败照片」；**不得生成缺少照片的相册**

### F08~F09 生成
- [ ] 50 张照片 < 3min 出预览，进度阶段可见
- [ ] 输出严格符合 StoryOutput Schema（校验器 0 报错样本 ≥ 20 次生成）
- [ ] 三级信息分档正确：EXIF 事实直陈、推断中性表达、未知不提及
- [ ] 故事中不出现素材库之外的地名/人名（反虚构扫描通过率 100%）
- [ ] 全部生成失败路径最终产出模板文案且 degraded=true 明示

### F10 编辑
- [ ] 文字编辑、图说编辑、照片拖动排序持久化
- [ ] 单段重生成仅改动目标章节，其他章节与版本号联动正确
- [ ] 锁定段在整体重生成时跳过，内容不变
- [ ] 恢复上一版本正确回退
- [ ] 重生成时保留用户手动修改的段落

### F11 分享
- [ ] 分享链接 7/30/永久三种有效期正确
- [ ] 撤销后旧链接立即显示"已失效"
- [ ] 长图保存成功且包含标题/副标题/章节/照片/图说全部内容
- [ ] 相册默认私密，不默认公开
- [ ] token 权限检查通过（有效/撤销/过期/越权访问拦截）
- [ ] 可选分享摘要正确生成

### F12 删除
- [ ] 相册删除后：云存储原图+缩略图、photos/groups/story/albums/EXIF/位置数据/PhotoFact/AI 任务/分享链接/缓存全部无残留
- [ ] 账号级删除后 users 及全部关联数据清空（一键删除全部数据类型）
- [ ] 删除操作返回删除结果（已删除数量与类型）
- [ ] 相册访问和删除接口进行用户身份及资源归属校验
- [ ] 云函数日志抽查：无照片内容、GPS 原始值、完整敏感提示词、用户身份凭证、密钥明文

## 2. 测试场景表

| # | 场景 | 输入 | 预期 |
|---|------|------|------|
| T01 | 全新用户首启 | 未登录态 | 静默登录→隐私弹窗→空态首页 |
| T02 | 相册名边界 | 空 / 21 字 / 表情符号 | 空禁止提交；21 字截断提示；表情正常保存 |
| T03 | 原图上传 | 相册原图 10 张（EXIF 完整） | 时间地点全绿标，聚类合理 |
| T04 | 微信压缩图 | 聊天转发图 10 张（EXIF 全无） | 全部黄/灰标；文件时间兜底或引导补填 |
| T05 | 混合来源 | 5 张原图 + 5 张无EXIF | 排序以确定时间为锚，未知项可用户调整位置 |
| T06 | 无 GPS 有时间 | 时间 EXIF 完整、无 GPS | 时间绿标、地点灰标引导补填 |
| T07 | 境外 GPS | 经纬度 (48.85, 2.35) 巴黎 | 若开启"仅中国境内"→降级；关闭→正常逆解析 |
| T08 | GPS 漂移 | 相邻照片距离 800km | 标黄"疑似定位漂移"待确认 |
| T09 | 全无时间 | 20 张全部无时间信息 | 聚类按视觉内容连续性归组（"按内容归组"标注）；故事无日期标签 |
| T29 | 内容切组 | 同一天同地点：上午寺庙+下午海滩照片 | 时间/地点无法切分时，按内容切换分两组 |
| T10 | 时序矛盾 | 推断时间与确认时间乱序 >24h | confidence 降至 0.2，标黄 |
| T11 | 低置信推断入文 | inferred conf=0.4 的地标 | 不出现在 narrative 正文 |
| T12 | 虚构拦截 | 模型返回素材外地名（构造） | 校验失败→重试→不进入用户可见产物 |
| T13 | JSON 破损 | 模型返回非法 JSON（构造） | 三级降级最终模板文案，degraded=true |
| T14 | 生成中途删相册 | generating 状态删除 | 任务 cancelled；无孤儿文件 |
| T15 | 任务卡死 | 模拟 job running >30min | cleanup 标记 failed；前端可重试 |
| T16 | 单段重生成 | 带 feedback "更幽默" | 仅该章变化；反馈体现在新文本 |
| T17 | 照片漏图 | 生成的 chapters 未覆盖全部照片 | 引用完整性校验失败→重试 |
| T18 | 分享有效期 | 7 天链接第 8 天访问 | "链接已失效" |
| T19 | 分享撤销 | 撤销后立即访问 | "链接已失效" |
| T20 | 游客访问 | 未登录用户点开分享链接 | 可正常只读浏览 |
| T21 | 长图导出 | 50 张照片故事 | 保存成功，图片完整不裁切 |
| T22 | 上限压力 | 50 张混合照片全流程 | 3min 内完成生成；无超时报错 |
| T23 | 相册级删除 | 删除含 50 张照片相册 | 存储与数据库零残留（控制台抽查） |
| T24 | 账号注销 | 输入"删除"确认 | 全量清理+返回登录页 |
| T25 | 隐私告知 | 首次上传弹窗内容核对 | 含去向/用途/保存期/不用于训练四要素 |
| T26 | 限流 | 1 分钟内高频调用 | 触发 42901，前端友好提示 |
| T27 | 弱网生成 | 生成中切弱网 | 轮询退避，恢复后状态正确续传展示 |
| T28 | 并发生成 | 同相册连续点两次生成 | 40901 状态冲突拦截 |
| T30 | 批次中断续跑 | 20 张照片第 2 批执行中人为杀掉函数实例 | 重启任务后从第 3 批开始；第 1、2 批结果不重算（验证 batches 状态与模型调用次数） |
| T31 | 幂等重试 | 对同一 running 任务重复触发 requestMetaProcess | 仅未完成批次执行；无重复写库/重复调用 |
| T32 | 部分批次失败 | 30 张照片构造第 4 批视觉 API 持续失败 | 任务整体 failed；生成入口被 40903 拦截；前端列出失败照片并供重试/移除 |
| T33 | 移除失败照片后生成 | T32 中移除失败照片（剩 ≥5 张） | 可正常生成；故事只覆盖保留照片 |
| T34 | 4 张草稿 | 上传 4 张后退出 | 相册为 draft 可续传；「生成」置灰并提示至少 5 张 |
| T35 | 50 张上限阻断 | 已 50 张再点「添加照片」 | 不进入选择器，提示「已达 50 张上限，可删除或更换照片」；已选照片无任何丢失 |
| T36 | 格式检查 | 上传 BMP/RAW/TIFF 文件 | 拒绝并提示「不支持的格式，仅支持 JPEG/PNG/HEIC」 |
| T37 | 大小检查 | 上传 >20MB 的 JPEG | 拒绝并提示「文件过大，请压缩后上传」 |
| T38 | 损坏检查 | 上传损坏的 JPEG（修改文件头） | 拒绝并提示「文件损坏，无法读取」 |
| T39 | 重复检测 | 上传同一张照片两次 | 弹窗提示「检测到疑似重复照片，是否保留？」；用户可选择保留或删除 |
| T40 | 批量重试 | 10 张照片中 3 张失败 | 点「批量重试」仅重试失败项，成功项不受影响 |
| T41 | 锁定重生成 | 锁定 ch1 后整体重生成 | ch1 内容不变；其他章节重生成 |
| T42 | 恢复版本 | 编辑后恢复上一版本 | 回退到上一版本内容；版本号正确 |
| T43 | 越权访问 | 篡改 token 访问他人相册 | 拦截并显示「链接已失效」 |
| T44 | 一键删除 | 删除含 30 张照片的相册 | 返回删除结果（原图 30、缩略图 30、故事 1 等）；控制台抽查零残留 |

## 3. 性能与稳定性指标复核

| 指标 | 目标 | 测法 |
|------|------|------|
| 10 张上传（WiFi） | < 90s | 真机计时 ×3 取均值 |
| 50 张元数据全处理 | < 3min | ai_jobs 时间戳差 |
| 故事生成（50 张） | < 3min | 任务创建→succeeded |
| 断点续跑重算量 | 0 张（已完成批次不重跑） | 人为中断后核对模型调用次数 |
| 轮询 QPS | 单用户 ≤ 1/3s | 前端日志 |
| 生成成功率（含降级） | 100%（允许 degraded） | 20 次样本 |
| 纯 AI 成功率（非降级） | ≥ 85% | 20 次样本 |

## 4. 提审前自查清单

- [ ] 类目与资质：工具类目确认，无社交类目风险
- [ ] 微信隐私接口声明：相册（写入/读取）、保存图片、位置信息用途声明
- [ ] 用户协议与隐私政策链接可访问
- [ ] 分享卡片文案不含诱导用语
- [ ] 测试账号与体验版二维码就绪
