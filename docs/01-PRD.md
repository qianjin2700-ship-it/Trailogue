# 01 — 产品需求文档（PRD）

## 1. 产品概述

**产品名称**：旅迹成书（暂定名）
**产品形态**：微信原生小程序（独立发布）
**一句话定位**：上传 5～50 张旅行/活动照片，AI 自动读取拍摄时间与 GPS，结合图片内容理解，按**时间、地点及画面内容**自动排序、分组，再结合用户输入的主题、背景和文风提示词，生成一本有故事性的图文相册。

**核心价值**：
- 用户无需写作能力，只需提供照片和少量背景信息，即可获得结构完整（标题、序言、章节、图说、结尾）的旅行纪念册；
- 时间、地点、画面内容三维度自动排序分组，还原旅程叙事线，EXIF 缺失时也能靠内容理解兜底分组；
- 严格的事实约束机制：不虚构人物、关系、地点与事件，让 AI 内容可放心留存与分享。

## 2. 目标用户与画像

| 画像 | 描述 | 核心诉求 |
|------|------|---------|
| 年轻旅行者 | 20-35 岁，独自或情侣出游，拍照多但从不整理 | 快速产出可发朋友圈/小红书的图文故事 |
| 亲子家庭 | 记录带孩子出游的回忆，照片量大且杂 | 把几百张照片浓缩成一本"家庭相册书" |
| 活动/团建组织者 | 公司团建、班级活动、聚会后需要总结回顾 | 生成活动纪念文册，分享给参与者 |

## 4. 功能需求详述

### F03 照片上传
- 上传前提示：「原图将上传至云端用于生成故事，保存期限见隐私说明；不会用于模型训练」；
- `wx.chooseMedia` 选择原图（优先保留 EXIF），提醒用户尽量选择原图但不能假定系统一定能够获得原始文件；
- **支持格式**：JPEG/JPG、PNG、HEIC（iOS 原生）；单张大小限制 ≤ 20MB；损坏图片拒绝并提示；
- 上传前执行四项检查：①文件格式校验 ②文件大小校验 ③损坏检测（读取文件头） ④重复照片检测（文件 hash 或 EXIF+大小组合去重），重复照片提醒用户决定是否保留；
- 本地预压缩生成缩略图（长边 1080px）；原图与缩略图分别上传云存储；
- 上传过程显示：总体进度、单张照片状态、上传成功数量、上传失败数量、失败原因；
- 支持单张重试和批量重试；上传失败不能造成已成功照片丢失；
- 处理图片方向异常、超大图片、压缩图片、损坏图片和无 EXIF 图片；
- **数量规则（全局统一约束，所有文档以此为准）**：
  - 上限 **50 张**：达到 50 张后阻止继续选择（chooseMedia 按剩余额度取 count），提示「已达 50 张上限，可删除或更换照片」；
  - 少于 **5 张**：允许保存草稿、随时续传，但「生成故事」入口置灰并提示至少 5 张；
  - 达到 5 张即可生成；
  - **不得自动截断、丢弃或覆盖任何照片**——用户主动删除除外，系统侧永不做静默删除；
  - 上传页实时显示「已选择 X/50 张」；
  - 用户删除照片后可以继续补充上传。

### F04~F07 元数据、视觉与排序（详见 07 号文档）
- 云端用 exifr 解析 EXIF；GPS 逆解析调用腾讯位置服务；
- 三级降级：EXIF → 自动推断（标注置信度）→ 用户补充；
- 视觉理解在分组**之前**执行，图片内容（场景/地标相似度）作为聚类第三维度；
- 聚类规则：时间间隔 > 6h、地理距离 > 30km、或内容明显切换（不同场景/地标）开新章（阈值可配置）。

### F07 视觉理解
- 输出结构化「照片事实」（场景、地标、天气、昼夜、可见文字等），每条带置信度；
- 低置信度事实（< 0.6）仅作排序参考，不写入故事正文。

### F09 故事生成（详见 06 号文档）
- 两步生成：先「照片事实素材库」，后「故事」；
- 故事分四档信息来源：确定事实 / 模型推断 / 用户补充 / 未知信息，推断信息在文中使用中性表达，未知信息不提及或用模糊指代；
- 系统生成：相册标题、封面副标题、序言、章节标题、章节正文、单张或成组照片说明、结尾、可选分享摘要；
- 基础文风：温暖纪实 / 轻松幽默 / 文艺克制 / 亲子成长 / 青春活力 / 简洁客观 / 自定义文风；
- 用户可输入：旅行或活动主题、日期、城市或地点、人物关系、重要事件、希望强调的照片、文风、希望避免的表达；
- 生成失败自动重试 2 次，仍失败则降级为模板化文案并明确告知用户；
- 校验失败最多自动重试 3 次（含结构校验 + 事实引用完整性检查 + 地名一致性检查）。

### F10 编辑与重生成
- 用户可修改所有文案、单独重新生成某一段、调整文风；
- 支持锁定已经满意的内容（锁定段不被重生成覆盖）；
- 支持恢复上一版本；
- 重新生成时保留用户手动修改的内容（locked 标记或 user_edited 标记的段落跳过重生成）。

### F11 分享
- 相册默认**私密**，不得默认公开；
- 生成分享卡片，接收者打开小程序浏览相册页（分享 token 可撤销、可设有效期）；
- 分享凭证支持：撤销、失效时间、权限检查、防止越权访问；
- 长图：Canvas 2D 渲染标题+章节+照片+文案，保存到手机相册；
- 后续版本再考虑 PDF、视频、多人协作、公开社区和实体书制作，本期不实现。

### F11 分享
- 生成分享卡片，接收者打开小程序浏览相册页（分享 token 可撤销、可设有效期）；
- 长图：Canvas 2D 渲染标题+章节+照片+文案，保存到手机相册。

### F12 数据删除
- 相册级删除：原图、缩略图、EXIF 及位置数据、PhotoFact、AI 任务数据、故事内容、分享链接、相关缓存——全部覆盖主数据、云存储文件和可控缓存，并返回删除结果；
- 账号级删除：全部相册 + 用户档案 + 日志关联数据；
- 删除需二次确认，删除后不可恢复；
- 用户可以一键删除上述全部数据类型；
- 相册访问和删除接口必须进行用户身份及资源归属校验。

## 6. 隐私与数据安全需求

1. 上传前明确告知用户：照片是否上传云端、处理用途、保存时间、是否发送给第三方模型、是否用于模型训练；
2. **默认不得将用户照片用于模型训练**；
3. 原始照片、缩略图、GPS、AI 分析结果和故事内容均视为用户隐私数据；
4. 日志不得记录：原始照片、GPS 原始数据、完整敏感提示词、用户身份凭证、模型密钥；
5. 首次进入上传流程展示隐私告知弹窗（内容、用途、保存期 90 天/永久可选、不用于训练、是否发送给第三方模型）；
6. 相册默认私密，仅分享 token 持有者可见，token 可撤销、可过期、权限检查、防越权；
7. 日志规范：云函数日志仅记录 openid 哈希、任务 ID、耗时与状态码、Token 或计费量和错误码；但**不得记录敏感照片内容或完整提示词中的隐私信息**；
8. 删除操作级联清理云存储文件（原图/缩略图）+ 数据库文档 + 可控缓存，并返回删除结果。

## 7. 关键风险与对策

| 风险 | 对策 |
|------|------|
| 微信转发/压缩导致 EXIF 丢失 | 三级降级机制 + 上传时优先选原图 + 文件时间兜底 |
| 多模态模型幻觉（编造人名/地点） | 事实素材库先行 + 结构化 JSON 校验 + 禁止虚构的 prompt 约束 + 事后扫描 |
| 长任务超时（云函数单次执行限制） | 分批处理 + 任务状态表 + 前端轮询；云函数自调用续批 |
| 逆地址解析配额/费用 | 结果缓存（同经纬度 6 位小数去重）；失败降级为"坐标附近"表述 |
| 生成内容不符合预期 | 分段重生成 + 文风提示词 + 用户可全量编辑 |
