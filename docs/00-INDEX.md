## 技术栈总览

- 前端：微信原生小程序 + TypeScript
- 后端：CloudBase 云函数 / 云数据库 / 云存储
- 位置：腾讯位置服务 WebService API（逆地址解析），封装为可替换接口
- 多模态模型：腾讯云混元视觉模型（暂定）；**模型调用封装为可替换 Provider 接口**，避免业务逻辑与单一供应商强耦合；密钥仅存于云函数环境变量；模型调用必须设置超时/重试/幂等/并发上限/限流/降级策略
- 存储服务：CloudBase 云存储或腾讯云 COS，封装为可替换接口
- 长图生成：小程序端 Canvas 2D 离屏渲染
- 输出校验：AJV 或同类工具校验 AI 结构化输出
- 异步任务：状态机处理长任务，支持幂等/断点续跑/取消/重复检测
