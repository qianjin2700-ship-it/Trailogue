# Trailogue 首轮集中创作体验优化

**更新日期**：2026-10-28

## 交付范围

- My Trips 卡片与旅行详情直接展示不受时区影响的旅行日期；列表同时展示封面与地点。
- 新增独立创作要求页，持久化人物、关系、风格、篇幅、创作重点、特殊要求、生成语言和画册风格。只有用户点击“Start generating story”后才调用 DeepSeek。
- 故事历史页显示版本、时间、语言、风格和来源，支持全文查看、双版本差异以及“新增版本式”恢复。
- 书籍预览与 PDF 共用 `BookLayoutDocument`，支持封面、章节扉页、全幅、左右图文、双图、三图、重点大图加两张小图和图文混排。
- 支持旅行杂志、温馨回忆录与简约摄影集三种画册风格；图片使用裁切而非拉伸，固定页面边界避免文字溢出。
- PDF 实际分享文件名遵循 `旅行名称_YYYY-MM-DD.pdf`，非法字符会替换，标题长度受限，缺失日期时只保留名称。
- 自动语言识别以用户叙述为主，手动选择优先；每个版本记录语言模式和实际语言。
- DeepSeek 提示词将“照片事实提取”和“故事创作”分层，禁止虚构对话、心理、地点或精确时间，并抑制机械视觉清单。

## 数据库变更

迁移：`packages/database/drizzle/0004_creative_book_experience.sql`

该迁移只增加列、约束并回填新元数据，不删除表、列或既有故事。Railway 部署时由既有迁移机制执行；若数据库阶段失败，应停止部署并检查日志，不手工修改迁移 journal。

## 验证

- 根目录：`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`
- iOS：`npm run doctor`、`npm run build`
- PDF：实际生成代表性 13 页样本，自动检查页数、图片和空页，并渲染审查封面、章节页、双图与重点大图组合。

## 集中试用路径

1. 登录后打开已有旅行，确认列表卡片和详情标题下方的日期、封面与地点。
2. 上传并整理照片，设置封面；进入 Creative requirements 调整人物、风格、长度、重点、语言与画册风格。
3. 确认页面不会自动生成；点击 Start generating story 后检查目标语言、篇幅、人物互动与时间逻辑。
4. 编辑或重新生成故事，然后进入 History & compare 查看、比较并恢复旧版本。
5. 打开 Book preview，检查不同照片比例、多图页面和章节区分；导出后确认 PDF 版式与预览一致且文件名可辨认。
6. 重启 App，确认创作要求、照片、故事版本和书籍仍可读取。
