# 02 — 用户操作流程

## 1. 核心旅程总览

```
登录 → 创建相册 → 上传照片 → 元数据处理 → 元数据确认(三级降级)
     → 填写创作输入 → AI生成故事 → 编辑调整 → 预览 → 分享/导出长图
                                                        ↘ 数据管理/彻底删除
```

## 2. 流程 A：首次登录

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| A1 | 打开小程序 | wx.login 静默获取 openid，创建/读取 users 记录 |
| A2 | — | 首次使用时弹出隐私政策弹窗，须同意后进入 |
| A3 | （可选）点头像昵称授权按钮 | 更新 users 中的昵称头像 |
| A4 | 进入首页 | 展示相册列表（空态引导创建第一本相册） |

## 3. 流程 B：创建相册

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| B1 | 首页点「+ 创建相册」 | 进入创建页 |
| B2 | 填写：相册名（必填）、主题（如"青海湖环线"） | 前端校验长度 |
| B3 | 填写：活动背景（发生了什么）、人物关系（如"我和大学室友"）、想强调的内容 | 均为可选，作为生成提示词 |
| B4 | 选择文风：温暖纪实 / 轻松幽默 / 文艺克制 / 亲子成长 / 青春活力 / 简洁客观 / 自定义文风 | 单选，影响生成 prompt |
| B5 | 提交 | 创建 albums 记录（status=draft），跳转上传页 |

## 4. 流程 C：上传照片

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| C1 | 点「添加照片」 | wx.chooseMedia（count ≤ 50−已有数量，sizeType 含 original）；提醒用户尽量选择原图；**实时显示「已选择 X/50 张」** |
| C1b | 选择后自动检查 | ①格式校验（JPEG/PNG/HEIC）②大小校验（≤20MB）③损坏检测（文件头读取）④重复检测（文件 hash 或 EXIF+大小组合）；不通过项标红提示原因 |
| C1c | 重复照片提醒 | 检测到重复照片时弹窗提示「检测到疑似重复照片，是否保留？」用户逐张选择保留或删除 |
| C2 | 首次上传前 | 展示隐私告知弹窗（去向/用途/保存期/是否发送第三方模型/不用于训练），同意后不再重复弹出 |
| C3 | 确认选择 | 本地生成缩略图（长边 1080px）→ 逐张上传原图+缩略图；显示：总体进度、单张状态、成功数、失败数、失败原因 |
| C4 | 查看进度 | 每张照片显示独立进度条；失败项显示「重试」按钮；支持单张重试和批量重试；上传失败不能造成已成功照片丢失 |
| C5 | 上传完成 | 自动触发元数据处理任务（ai_jobs）：EXIF/逆解析 → 视觉理解，进入处理页；处理阶段实时展示（解析中→图片理解中） |
| C6 | 照片总数 <5 时点「生成故事」 | **允许保存草稿**；「生成」按钮置灰，提示「至少 5 张照片才能开始生成」 |
| C7 | 已达 50 张再点「添加照片」 | 阻止进入选择器，提示「已达 50 张上限，可删除或更换照片」；**系统不得自动截断/丢弃/覆盖照片** |
| C8 | 用户删除照片后 | 可继续补充上传，计数相应更新 |

## 5. 流程 D：元数据确认（三级降级交互核心）

```
处理完成 → 展示"时间轴 + 地点"确认页
   ├─ 全部高置信度 → 一键确认，直接进入下一步
   ├─ 存在低置信度项 → 逐项卡片式确认：
   │     [EXIF确认]      显示"2026-08-15 14:32 · 西宁市城中区"（绿色徽标）
   │     [推断待确认]    显示"可能是傍晚的海边（置信度 55%）"（黄色徽标）
   │                       → 用户可选：✔采纳 / ✏️修改 / ❓标为未知
   │     [完全未知]      显示"拍摄时间未知"
   │                       → 引导补填日期或城市；可跳过
   └─ 用户补充信息覆盖系统推断，标记 source=user
```

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| D1 | 查看照片时间轴 | 按（已确定的）时间排序展示，分组预览 |
| D2 | 对黄色/灰色项操作 | 采纳 / 修改 / 标为未知，写回 photos 文档 |
| D3 | 点「确认并生成」 | 按**时间+地点+图片内容**聚类分组 → 生成「照片事实素材库」（含用户补充），快照存入 album_stories.fact_base |
| D4 | — | 展示关键信息摘要页（时间范围、地点列表、未知项数量），允许返回修改 |

## 6. 流程 E：AI 生成故事（异步）

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| E1 | 在摘要页点「开始生成」 | **前置校验**：≥5 张；所有照片处理完成（无 pending/failed 批次）；如有失败照片须先重试成功或移除。通过后创建 story 类型 ai_job，相册 status=generating |
| E2 | 等待（可离开页面） | 云函数分批执行：素材库组装 → 逐章生成 → 汇总（视觉理解已在 D 阶段前完成） |
| E3 | 轮询进度 | 前端 3s 间隔轮询 getJobStatus（指数退避，上限 30s；总超时 10min）；展示完整阶段链：上传 → 解析 → 图片理解 → 排序与分组 → 生成故事 → 生成相册；显示「正在分析第 X/Y 批照片」和预计处理时间（不承诺固定完成时间） |
| E4 | 完成通知 | 相册 status=done，跳转故事预览页 |
| E5 | 失败 | 显示失败原因 + 失败照片列表 + 选项：「重试失败批次」「移除失败照片」「返回编辑」「取消本次生成」 |

## 7. 流程 F：编辑与重生成

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| F1 | 进入编辑模式 | 章节卡片列表，每段含：标题、正文、图说、锁定开关 |
| F2 | 长按拖动照片 | 调整章内照片顺序（写回 photos.sort_index）；系统不在用户未确认时永久改变原始照片顺序 |
| F3 | 点击文字 | 行内编辑标题/正文/图说（保存新版本 story.version+1） |
| F4 | 点某段「重新生成」 | 单段重生成（携带该章事实子集 + 用户反馈语），其余不动；**已锁定的段落跳过重生成** |
| F5 | 调整章节标题 | 直接编辑，不触发 AI |
| F6 | 点「锁定」 | 标记段落为已锁定，后续整体重生成时跳过此段 |
| F7 | 点「恢复上一版本」 | 回退到 story.version-1 的内容 |
| F8 | 整体重生成 | 保留用户手动修改/锁定的段落，仅重生成未锁定段 |

## 8. 流程 G：分享与长图

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| G1 | 点「分享」 | 创建 share token（可选有效期：7天/30天/永久）；生成可选分享摘要 |
| G2 | 转发卡片给好友/群 | 好友打开 shared-view 页，凭 token 浏览（只读）；**权限检查**：token 有效性、归属校验、防越权访问 |
| G3 | 「生成长图」 | Canvas 2D 逐章渲染 → 保存到相册（需授权） |
| G4 | 「撤销分享」 | token 置 revoked，旧链接立即失效 |

## 9. 流程 H：数据删除

| 步骤 | 用户动作 | 系统行为 |
|------|---------|---------|
| H1 | 相册详情 → 「删除相册」 | 二次确认弹窗（列出将删除的内容类型） |
| H2 | 确认 | 删除云存储原图+缩略图 → 删除 photos/groups/story → 删除 albums；进行中的任务标记取消 |
| H3 | 设置页 → 「注销并删除全部数据」 | 滚动确认清单 + 输入「删除」二字确认 → 全量清理（H2 全相册循环 + users + 任务记录） |
| H4 | — | 删除完成后本地缓存清理，返回登录页 |

## 10. 异常流程

| 场景 | 处理 |
|------|------|
| 上传中断网 | 失败项标红，恢复网络后点「重试失败项」续传 |
| 处理任务卡住 >5min | 前端提示 + 提供重启任务按钮（服务端幂等，已完成批次不重跑） |
| **部分批次失败** | 任务标记 failed，**不得生成缺少照片的相册**；失败照片列表提示用户选择：「重试失败批次」「移除失败照片」「返回编辑」「取消本次生成」；全部处理后才能继续生成 |
| 批次处理中断（函数超时/崩溃） | 每批结果已持久化（photos 字段即时写回 + ai_jobs.batches 状态），断点续跑从下一个未完成批次开始 |
| 生成结果 JSON 校验失败 | 自动重试 2 次 → 降级模板文案 + 标记「部分内容为模板生成」 |
| 分享链接已撤销/过期 | 展示「链接已失效」页 |
| 用户在生成中途删除相册 | 任务取消标记，孤儿文件由清理逻辑兜底删除 |
