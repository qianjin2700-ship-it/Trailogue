# Trailogue 智能旅行画册 V3.0 照片自适应与视觉验收报告

## 验证素材与结论

本轮继续使用 V2 的同一组 17 张桂山岛参考照片和同一份四章中文故事，未替换照片、未修改故事来规避排版问题。照片来自既有样本目录，不读取或修改 Neon 数据。

V3 的关键变化不是增加模板，而是让照片尺寸、方向和裁切安全先参与版式选择：系统先排除会造成明显不安全裁切的方案，再以照片适配、主体安全、展示面积、风格匹配和节奏进行确定性评分。无法可靠识别人脸或主体时，竖图和狭长竖图采用保守的 `contain` 回退；本轮没有引入或声称使用新的视觉 AI 主体检测。

## V2 根因与 V3 修复

| V2 根因                            | 结果                             | V3 处理                                                         |
| ---------------------------------- | -------------------------------- | --------------------------------------------------------------- |
| 极简风格按固定节奏把照片拆为单图页 | 17 页、节奏零散、小图独占页面    | 三图章节合并为一页，四/五图章节采用 2+2 或 3+2，最终 9 页       |
| PDF 全局使用 `object-fit: cover`   | 页面字段中的 `imageFit` 实际无效 | 每张照片保存独立 fit、焦点、容器比例和可见比例，HTML 按原值渲染 |
| App 使用通用网格，PDF 使用独立 CSS | 预览与导出裁切可能不一致         | React Native 预览按相同 fit/focus 公式计算缩放和偏移            |
| 样本脚本伪造照片宽高               | 无法验证真实构图                 | JPEG SOF 读取真实像素尺寸后再规划                               |
| 固定模板轮换不看照片比例           | 横图进竖框、人物图进狭框         | 候选版式评分，主体安全权重最高，不达阈值自动完整展示            |
| 空说明仍渲染 `figcaption`          | 双图页出现无意义灰条             | 空说明不输出标签                                                |

## V2 与 V3 对照

| 风格                  |    V2 |    V3 | 视觉结果                                                                               |
| --------------------- | ----: | ----: | -------------------------------------------------------------------------------------- |
| Travel Magazine       | 10 页 | 10 页 | 保留章节大图、拼贴和强标题；横向封面/章节改为上部大图与独立文字区；照片不再整体暗化    |
| Warm Memoir           | 10 页 |  9 页 | 取消孤立竖图页；人物主图、人物与场景三图、双横图交替；暖色纸张和故事卡片与极简风格分离 |
| Minimalist Photo Book | 17 页 |  9 页 | 由逐图分页改为大图组合；正文缩为章节摘要；照片仍保留完整故事数据，不删除故事内容       |

页面重排后不按旧页码强行一一对应，而按章节和照片 ID 对照：

- `walk / photo-1..3`：V2 中开篇与孤立单图拆页，V3 合并为一张人物主图加两张场景图。
- `lighthouse / photo-4..8`：横向海景和灯塔使用宽图组合；人物照片不进入狭长横框。
- `sunset / photo-9..12`：代表晚霞用于横向大图，人物合影保持完整；杂志页仅在文字区域做局部渐变。
- `night / photo-13..17`：夜景、秋千、投影与晚餐采用主辅组合，不再一张小图占一页。

## 自动质量检查

`tmp/pdfs/guishan-v3-layout-audit.json` 记录了可重复的布局审计结果：

- Travel Magazine：10 页，0 项布局质量告警。
- Warm Memoir：9 页，0 项布局质量告警。
- Minimalist Photo Book：9 页，0 项布局质量告警。
- 三种风格自动裁切的最低保留面积均不低于 86%。
- 竖图/狭长竖图在没有主体信息且无法达到 95% 保留目标时回退为完整展示。
- 单页最多 4 张照片；无短文字空白页；无连续三页相同版式；无缺失 placement。

测试还覆盖：EXIF 5–8 方向交换宽高、横/竖/方图分类、裁切保留比例、保守回退、预览/PDF 参数一致、手工 fit 与焦点持久化、V2 布局兼容升级、日期和 PDF 文件名。

## 真实 PDF 视觉复查

三份 PDF 均由最终 HTML 实际打印，全部页面以 90 DPI 渲染为 JPEG 并生成接触表。视觉复查包括：封面、章节分隔、人物完整性、灯塔和海景构图、留白、图文重叠、空说明横条、中文字体和页数。

第一轮复查发现温馨/极简存在孤立竖图页，第二轮发现空 `figcaption` 灰条；两项均修复后重新生成全部 PDF。最终接触表未发现明显图片拉伸、人物头部裁断、文字溢出或无意义的单张小图页。

## 已知边界

- 当前没有可靠的人脸框、主体框或用户手绘安全区数据，因此不会假装完成主体识别；自动策略以宽高比、保留面积和保守 `contain` 为基础。
- 用户可在 App 中切换首图 fit 并循环移动垂直焦点；尚未提供复杂自由拖拽裁切编辑器，符合本轮边界。
- 接触表适合整体节奏检查；最终打印色彩仍会受 iPhone 屏幕、PDF 查看器和打印设备色彩管理影响。
