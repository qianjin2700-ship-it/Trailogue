# Trailogue 画册 V4：参考图视觉对齐

本轮以用户提供的《桂山岛旅行摄影书提案》为直接视觉基准，调整共享页面模型、iOS 预览和 PDF 渲染。不是新增一组仅供展示的静态模板；三种风格继续使用真实旅行、故事和照片数据，并由照片比例驱动布局与安全裁切。

## 三套视觉语法

- **旅行杂志**：上部宽幅封面照片、深蓝标题区、满版章节扉页、不对称图组和局部白色编辑块。无文字的照片页会自动扩大图片区域，避免空白来自模板能力不足。
- **温馨回忆录**：暖色纸张纹理、中央纪念卡封面、轻阴影照片层和柔和文字卡。装饰保持克制，避免影响人物和故事。
- **简约摄影集**：宽幅封面照片、章节页 23% 信息侧栏和 77% 影像区、窄间距照片带。章节标题、日期、地点和正文集中于侧栏，照片保持主导。

## 数据与兼容

- 布局文档版本由 V3 升级为 V4。
- V2/V3 自动布局在打开时按 V4 重新规划。
- 用户手工调整过的页面继续保留，不因升级丢失。
- 用户选定的封面照片继续优先；横幅照片不会为了模拟竖版封面而进行危险裁切。
- App 预览和 PDF 使用同一 `BookLayoutDocument`，封面变体、信息侧栏和照片组合一致。

## 视觉验收样本

三种样本均使用同一组桂山岛真实照片和同一故事内容生成，并逐页渲染为联系表检查：封面、图片比例、文字溢出、无意义留白、章节层次、中文字体和页码均可见。布局审计未发现缺失照片位置、危险裁切、短空白页或连续重复版式。

样本文件位于 `output/pdf/Trailogue-Guishan-*-V4-reference.pdf`，对应联系表位于同目录的 `*-contact-sheet.jpg`。
